# Archivo 2024 · José Luis Becerril

**Esta carpeta no forma parte del curso 2027.** Para las prácticas usa las carpetas `sesion_01_…` a `sesion_08_…`.

Contiene, sin cambios, los archivos que José Luis Becerril subió a este repositorio entre el 10 de junio y el 15 de julio de 2024 para la primera generación de Jabil (último commit `e7ffed1`), con sus nombres y su organización originales (`sesion_0` a `sesion_8`).

| Carpeta | Contenido |
|---|---|
| `sesion_0` | Cuaderno de presentación |
| `sesion_1` | Divisor con termistor: programa de Arduino, programa de MATLAB y datos combinados |
| `sesion_2`, `sesion_3` | Potenciómetro lineal y rotatorio: MATLAB y Arduino |
| `sesion_4` | Análisis de error: MATLAB, figura y detalle |
| `sesion_5` | Temperatura contra tiempo: MATLAB y figura |
| `sesion_6` | Datos del SIMAJ 2022, regresión lineal y ARIMA (Python) con sus figuras |
| `sesion_7` | Mantenimiento predictivo de un motor: cuaderno, programa y datos |
| `sesion_8` | Uso de ChatGPT: cuaderno y temario |

El curso 2027 retiró MATLAB y Arduino; el archivo del SIMAJ (`sesion_6/datos_2022.xlsx`) se sigue usando y tiene su copia en `sesion_06_series_de_tiempo_y_pronostico/datos/`.
